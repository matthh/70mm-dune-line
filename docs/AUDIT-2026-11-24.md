## Security

### S-1 · Developer contact email embedded in scraper User-Agent — Info

**File:** `scripts/scrape.mjs:16`

The developer's personal email address is hardcoded in the User-Agent string
used by the scraper. This is intentional (fan-project contact info for the
wiki maintainer) and committed to a public GitHub repo, visible in HTTP logs
on the wiki server. Accepted risk for this project; noted for awareness.

**Recommended fix (optional):** Replace with a GitHub issues URL to reduce
email exposure, e.g. `contact: https://github.com/matthh/70mm-dune-line/issues`.

---

### S-2 · GitHub Actions `contents: write` — open, pre-existing, Info

**File:** `.github/workflows/refresh.yml:17`

The daily refresh workflow has `permissions: contents: write` (intentional —
it must commit updated `movies.json`). A compromised Actions token or a
malicious dependency in the scraper could push arbitrary commits. No new
exposure this cycle.

## Maintainability

### L-1 · `.at-row.clickable` hover/cursor styles have no effect — open since 2026-06-09

**File:** `app/globals.css:504, 662–664`

`display: contents` removes the box model; `background`, `cursor`, and
border-radius on `.at-row.clickable` do not render. Click events fire correctly.

**Recommended fix:** Change `.at-row` to `display: grid; grid-column: 1 / -1`
or restructure leaderboard rows so the clickable wrapper is not `display: contents`.

---

### L-2 · Non-null assertion `m.sum!` in `toCatalogMovie` — open since 2026-09-01

**File:** `lib/data.ts:425`

Call sites pre-filter `m.sum != null`, so no runtime NaN today. A future
refactor could break this silently.

**Recommended fix:** Type `CatalogMovie.sum` as `number | null` and remove the
assertion, or add a runtime guard inside `toCatalogMovie`.

---

### L-5 · No unit tests — open since 2026-06-09

**File:** `lib/data.ts`

`buildTimeline()`, `shortenThemeName()`, `categoryFor()`, and `isRegular()` are
pure functions with no test coverage.

**Recommended fix:** Add `vitest` and a `lib/data.test.ts` covering at minimum
`categoryFor()`, `isRegular()`, `shortenThemeName()`, and the null-episode sort
tiebreaker in `buildTimeline()`.
