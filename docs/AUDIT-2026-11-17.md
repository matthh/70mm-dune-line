## Security

### S-1 · Next.js GHSA-mfr8-8qww-v76h — ✅ Fixed 2026-11-17

**Severity:** Moderate  
**File:** `package-lock.json` (next@16.3.0–16.4.4 affected)

Information disclosure across root params when `'use cache'` is called through
`unstable_cache()`. This app uses neither feature (fully static export, no
server-side caching functions), so there was no active exposure, but the
dependency was upgraded to next@16.4.6 for defence-in-depth.

**Fix applied:** `npm audit fix` → next@16.4.6. Build verified.

## Maintainability

### M-1 · Workflow commit-message count overstated — ✅ Fixed 2026-11-17

**File:** `.github/workflows/refresh.yml` (commit step)

`COUNT` calculation previously used `d.movies.filter(m=>!m.vault).length` (→ 388).
Now uses full `isRegular()` predicate, consistent with `lib/data.ts`. Future
refreshes will report the correct 346 regular episodes in commit messages.

---

### L-1 · `.at-row.clickable` hover/cursor styles have no effect — open

**File:** `app/globals.css:504, 662–664`

`display: contents` removes the box model; `background`, `cursor`, padding, and
border-radius on `.at-row.clickable` do not render. Click events fire correctly.
Open since 2026-06-09.

**Recommended fix:** Change `.at-row` to `display: grid; grid-column: 1 / -1`
or restructure leaderboard rows so the clickable wrapper is not `display: contents`.

---

### L-2 · Non-null assertion `m.sum!` in `toCatalogMovie` — open

**File:** `lib/data.ts:425`

Call sites pre-filter `m.sum != null`, so no runtime NaN today. A future refactor
could introduce a silent NaN.

**Recommended fix:** Type `CatalogMovie.sum` as `number | null` and remove the
assertion, or add a runtime guard inside `toCatalogMovie`.

---

### L-5 · No unit tests — open

**File:** `lib/data.ts`

`buildTimeline()`, `shortenThemeName()`, `categoryFor()`, and `isRegular()` are
pure functions with no test coverage.

**Recommended fix:** Add `vitest` and a `lib/data.test.ts` covering at minimum
`categoryFor()`, `isRegular()`, `shortenThemeName()`, and the null-episode sort
tiebreaker in `buildTimeline()`.
