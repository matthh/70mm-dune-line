### L-1 · `.at-row.clickable` hover/cursor styles have no effect — open

**File:** `app/globals.css:504–505, 662–664`

`display: contents` removes the box; `background`, `cursor`, and box-model
properties on `.at-row.clickable` do not render. Click events still fire.
Open since 2026-06-09.

**Recommended fix:** Change `.at-row` to `display: grid; grid-column: 1 / -1`
or restructure leaderboard rows so the clickable wrapper is not
`display: contents`.

---

### L-2 · Non-null assertion `m.sum!` in `toCatalogMovie` — open

**File:** `lib/data.ts:425`

Call sites filter `m.sum != null` before reaching `toCatalogMovie`, so no
runtime NaN today. A future refactor could break this silently.

**Recommended fix:** Type `CatalogMovie.sum` as `number | null` and remove
the assertion, or add a runtime guard inside `toCatalogMovie`.

---

### L-3 · `'Holy/Regligion/Spiritual Month'` typo key in SHORT_NAMES — open

**File:** `lib/data.ts:158`

The key mirrors the wiki source data verbatim (typo is in the wiki). If the
wiki corrects the spelling the override silently stops firing.

**Recommended fix:** Add an inline comment noting the typo is from the wiki
source so a future editor does not "fix" it and break the match.

---

### L-5 · No tests — open

**File:** `lib/data.ts`

`buildTimeline()`, `shortenThemeName()`, `categoryFor()`, and `isRegular()`
are pure functions with no test coverage.

**Recommended fix:** Add `vitest` and a `lib/data.test.ts` covering at
minimum `categoryFor()`, `isRegular()`, `shortenThemeName()`, and the
null-episode sort tiebreaker in `buildTimeline()`.
