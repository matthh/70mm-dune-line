## Medium

### M-1 · PostCSS 8.4.31 XSS vulnerability in build toolchain — carry-over from 2026-07-21
**Dependency:** `postcss@8.4.31` (transitive via `next@16.2.6` → postcss)
**CVE:** GHSA-qx2v-qp2m-jg93
**Finding:** The deployed static bundle is not affected — PostCSS runs only at
build time and in CI. However, the vulnerability exists in the local dev
environment and the GitHub Actions runner.
**Fix:** Bump `next` lower bound to `^16.2.9` in `package.json` and run
`npm install`. `next@16.2.9` pulls `postcss@8.4.49` which resolves the CVE.
(The-Daily repo completed this upgrade on 2026-06-23.)

### M-2 · GitHub Actions `contents: write` permission too broad — carry-over from 2026-07-21
**File:** `.github/workflows/refresh.yml` (lines 17–18)
**Finding:** `permissions: contents: write` is set at the workflow level. The
`node scripts/scrape.mjs` step runs untrusted network I/O (against 70mmwiki.com
and Spotify's oEmbed endpoint) while the elevated token is available.
**Fix:** Set `contents: read` at the top level; override with
`contents: write` only for the git commit/push step using a dedicated job or
a `permissions:` override on just the relevant step.

## Low

### L-1 · `.at-row.clickable` hover styles have no effect — carry-over from 2026-06-09
**File:** `app/globals.css` (lines ~504, ~662–664)
**Finding:** `.at-row { display: contents; }` means all box-model properties
(cursor, background, border-radius) applied to `.at-row.clickable` have no
effect. The intended click-affordance styling for leaderboard rows never renders.
**Fix:** Change `.at-row` to `display: flex` or `display: grid` (matching
its parent's layout), or restructure the leaderboard grid to avoid
`display: contents`.

### L-2 · Hardcoded Dune wiki id `91` — accepted known assumption
**File:** `lib/data.ts:272`
**Finding:** `const isDune = m.id === 91`. If the wiki re-keys this entry,
the Dune Line categorisation silently breaks.
**Status:** Accepted. The wiki has never re-keyed a movie; the value is
stable by convention.

### L-3 · `MONTH_THEME_OVERRIDES` map accumulates stale entries — carry-over from 2026-07-21
**File:** `scripts/scrape.mjs` (lines 27–61, 34 entries)
**Finding:** Manual correction entries are never pruned automatically. The
scraper logs `REDUNDANT` warnings when the wiki catches up, but these are
not surfaced in CI.
**Fix:** Periodically run `node scripts/scrape.mjs` and grep the output for
`REDUNDANT`; remove flagged entries.

### L-4 · `isVisible` defined inside component with suppressed lint warning — carry-over from 2026-07-21
**File:** `app/Timeline.tsx` (line 128, eslint-disable on line 166)
**Finding:** `isVisible` is a plain function inside the component body, called
inside a `useMemo` whose dependency array suppresses
`react-hooks/exhaustive-deps`. Correct today but fragile if the function
signature changes.
**Fix:** Memoize `isVisible` with `useCallback` so it can appear in the
dependency array legitimately.

### L-5 · No test suite — carry-over from 2026-07-21
**Status:** Not fixed. `lib/data.ts` is entirely pure functions.
**Fix:** Add `vitest` and cover `buildTimeline`, `categoryFor`,
`shortenThemeName` using `data/movies.json` as the test fixture.
