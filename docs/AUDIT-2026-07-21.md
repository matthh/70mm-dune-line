## Medium

### M-1 · PostCSS 8.4.31 XSS vulnerability in build toolchain — carry-over from 2026-07-14
**File:** `package.json` (via `next@^16.2.4`)
**Status:** **Not fixed.** The pinned range `^16.2.4` still resolves to Next.js 16.2.4, which
pulls PostCSS ≤ 8.4.31 (CVE GHSA-qx2v-qp2m-jg93, moderate). PostCSS is a build-time
tool — the deployed static bundle is unaffected — but the vulnerability exists in the local
dev and CI environments.
**Fix:** `npm install next@latest` (or pin to `^16.2.9`), which pulls in postcss ≥ 8.5.10.
Verify `npm run build` still produces a clean static export after the upgrade.

### M-2 · GitHub Actions `contents: write` permission too broad — carry-over from 2026-07-14
**File:** `.github/workflows/refresh.yml`
**Status:** **Not fixed.** `contents: write` is scoped at the job level, applying to the
entire workflow.
**Fix:** Set `contents: read` at the top level; override with `contents: write` only for the
`git push` step, or use a fine-grained PAT scoped to this repository only.
